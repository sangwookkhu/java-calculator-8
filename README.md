# java-calculator-precourse

## 문자열 덧셈 계산기 구현 기능 목록

### 1. 입력 및 출력 관리
- 입력 받기: 사용자로부터 덧셈할 문자열을 입력한다.
- 결과 출력: 계산된 덧셈 결과를 사용자에게 정확하게 출력한다.
- 예외 처리 및 종료: 유효성 검증 실패 시 발생하는 `IllegalArgumentException`을 적절히 처리하고, 오류 메시지를 출력한 후 애플리케이션을 종료한다.

### 2. 문자열 파싱 및 분리
- 빈 문자열 처리: 입력 문자열이 null이거나 빈 문자열("")인 경우, 분리 과정 없이 0을 반환한다.
- 커스텀 구분자 추출: 문자열이 //로 시작하고 \n을 포함하는 경우, 그 사이의 문자를 커스텀 구분자로 추출한다.
- 구분자를 이용한 분리: 기본 구분자 (쉼표 , 또는 콜론 :)와 추출된 커스텀 구분자를 모두 활용하여 문자열을 숫자로 분리한다.

### 3. 유효성 검증 
- 숫자 형식 검증: 분리된 각 요소가 양의 정수 형식인지 확인하고 숫자 이외의 문자가 포함된 경우 `IllegalArgumentException`을 발생시킨다.
- 음수 검증: 분리된 각 요소에 음수가 포함되어 있는 경우 `IllegalArgumentException`을 발생시킨다. (0 또는 양수만 허용)

### 4. 덧셈 계산
- 최종 합산: 모든 유효성 검증을 통과한 분리된 숫자들의 총합을 계산하여 반환한다.
